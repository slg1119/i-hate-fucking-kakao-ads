통합 테스트는 실제 설치 앱 또는 검증된 원본 백업에서 만든 임시 복사본으로 수행했다. 테스트가 설치된 카카오톡을 변경하지 않았음을 해시로 확인했다. 사용자 설치본은 원본 해시이며 원본 백업의 1,558개 항목도 일치하는 상태로 확인했다.

GUI 작업 중 종료를 방지하는 처리를 추가했다. 복사본 준비 이후 교체 전 해시를 다시 확인하고, 교체 실패 시 이전 앱을 되돌리는 shell trap을 사용한다. 실제 관리자 비밀번호 입력과 사용자의 계정 로그인, 모든 카카오톡 화면, 실제 광고 배너 제거 결과는 자동 검증 범위에 포함하지 않았다.

사용자 요청에 따라 적용·복구·복원 시 선택된 앱 경로와 bundle ID가 일치하는 실행 인스턴스에 `NSRunningApplication.forceTerminate()`를 호출하도록 했다. 최대 5초 동안 종료를 확인하고 실패하면 파일 교체를 중단한다. 사용자의 실제 카카오톡을 강제로 종료하는 테스트는 수행하지 않았다.

DMG는 Developer ID 서명·Apple 공증을 포함하지 않는 실험 배포본이다. 공개 릴리스도 prerelease로 표시한다.
