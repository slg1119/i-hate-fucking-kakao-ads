# 카카오 광고 정리

macOS 카카오톡의 하단 광고 영역을 숨기는 네이티브 GUI입니다. 설치된 카카오톡을 자동 백업하고 **같은 경로에 적용**합니다. 기존 카카오톡 아이콘을 계속 사용하며 원본 복원도 지원합니다.

**실험 버전입니다.** 분석된 빌드에만 적용할 수 있습니다. 실제 계정의 로그인 유지와 모든 화면 동작은 보장하지 않습니다.

[DMG 다운로드](https://github.com/slg1119/i-hate-fucking-kakao-ads/releases)

## 사용 방법

1. DMG의 **카카오 광고 정리.app**을 Applications에 넣습니다.
2. 앱을 열어 카카오톡 경로와 버전을 확인합니다.
3. **백업하고 적용**을 누르고 앱별 서명 예외 설명을 읽은 뒤 선택합니다.
4. 선택된 경로의 카카오톡이 실행 중이면 자동으로 강제 종료합니다. 쓰기 권한이 필요하면 macOS가 관리자 인증을 요청합니다.
5. 기존 카카오톡을 열어 광고 영역과 로그인을 확인합니다.

**원래대로 복원**은 백업 전체를 검사한 뒤 원본 앱을 되돌립니다. 백업은 `~/Library/Application Support/NoAdKakao/Backups`에 저장됩니다. 대화와 설정을 수정하는 기능은 없습니다.

적용·복구·복원 모두 실행 중인 대상 카카오톡을 강제 종료합니다. 작성 중인 내용이 저장되지 않을 수 있습니다. 종료가 확인되지 않으면 파일 교체를 중단합니다.

이전 개발 버전 적용 후 실행되지 않으면 **실행 오류 복구**가 표시됩니다. 검증된 원본 백업에서 앱을 다시 준비하고 서명 예외를 적용합니다. 원본 복원도 선택할 수 있습니다.

## 지원 범위

- Apple Silicon Mac, macOS 14 이상 빌드 대상.
- 카카오톡 **26.9.0 (2006)**의 분석된 바이너리. 전체 SHA-256까지 같아야 합니다.
- arm64 코드만 수정합니다. Intel 및 Rosetta 실행은 지원하지 않습니다.
- 업데이트된 바이너리는 자동으로 거부합니다.

## 서명과 권한

광고 코드를 수정하면 카카오의 원래 서명은 유지할 수 없어 로컬 임시 서명으로 다시 서명합니다. 원래 App Sandbox와 기능 권한은 보존합니다.

임시 서명에는 Team ID가 없습니다. Hardened Runtime을 유지하며 포함된 라이브러리를 불러오기 위해 카카오톡과 보조 앱에 `com.apple.security.cs.disable-library-validation` 예외를 추가합니다. **해당 앱이 다른 개발자가 서명한 라이브러리도 불러올 수 있도록 보호가 완화됩니다.** GUI는 적용·복구 전에 설명과 동의를 제공합니다. macOS 전체 보안 설정과 SIP는 변경하지 않으며 원본 복원 시 예외도 제거됩니다.

macOS 권한 확인이나 재로그인이 필요할 수 있습니다. 중요한 대화는 카카오톡 자체 백업 기능으로 보관한 뒤 사용하세요.

배포 도구 자체는 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 포함하지 않습니다. 다운로드한 앱이 첫 실행 때 차단되면 소스와 배포 출처를 확인한 뒤 시스템 설정의 개인정보 보호 및 보안에서 해당 앱의 실행을 허용할 수 있습니다.

## 빌드와 검증

Xcode 명령줄 도구가 설치된 Mac에서 실행합니다. 외부 라이브러리를 다운로드하지 않습니다.

```sh
bash scripts/build.sh
bash scripts/test-loader.sh
bash scripts/package-dmg.sh
```

통합 테스트에는 분석된 카카오톡 원본 또는 이 도구의 원본 백업이 필요합니다. 임시 복사본에서 테스트하며 설치된 카카오톡은 수정하지 않습니다.

```sh
"dist/카카오 광고 정리.app/Contents/MacOS/NoAdKakao" --self-test
```

버전 거부, 동의 요구, 설치 직전 실패, 동일 경로 교체, 중첩 코드 서명, 라이브러리 검증 예외, 이전 버전 복구, 백업 변조 거부, 원본 전체 복원을 검증합니다. 별도 C 테스트로 Hardened Runtime을 켠 임시 서명 실행 파일의 실제 라이브러리 로딩도 확인합니다. 실제 카카오톡 계정의 전체 동작 검증과는 별개입니다.

## 소스 구성

- `Sources/PatchCore.swift`: 해시, 백업, 패치, 재서명, 교체·복원.
- `Sources/KakaoPatchApp.swift`: SwiftUI 화면과 동의 흐름.
- `Sources/EngineTests.swift`: 원본을 사용하는 임시 복사본 통합 테스트.
- `Tests/`: 독립적인 dyld 로더 회귀 테스트.
- `scripts/`: 빌드, 아이콘 생성 및 DMG 패키징.
- [패치 분석](docs/ANALYSIS.md), [실행 오류 분석](docs/SIGNING-FAILURE.md).

카카오톡 바이너리·리소스·사용자 오류 보고서는 저장소나 DMG에 포함하지 않습니다. 카카오와 관계없는 개인 프로젝트입니다.
